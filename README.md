# 浜名湖うなぎ

> このブランチ `design/editorial` は、main で公開中のサイトとは別に制作したデザイン案です。比較用に保存しています。

静岡県・浜名湖のうなぎを紹介する、静的な日本語 Web サイトです。海と湖が出会う汽水湖の環境、明治から続く養鰻の歴史、おいしさの理由、蒲焼きの味わい方、浜名湖周辺の旅を、雑誌のように読み進められる構成にしています。

## ページ構成

- **Hero** — 浜名湖うなぎの世界観を伝えるタイトルと、うなぎのエンブレム
- **01 About** — 汽水湖としての浜名湖、養殖の歴史、湖の基本データ
- **02 Why Delicious** — 水・気候・餌・職人の技という4つの視点
- **03 History** — 1891年から現在までの歩みをたどる年表
- **04 Life Cycle** — 卵から銀うなぎまでの一生
- **05 Taste** — 蒲焼きができるまでの4工程と、うな重・白焼き・うざくの味わい方
- **06 Lake Hamana** — 舘山寺温泉、弁天島、浜松城などの周辺案内とモデルコース
- **07 FAQ** — よくある質問
- **404** — サイトの雰囲気に合わせたエラーページ

## デザイン

- 深い藍色と生成り、金色、朱色で構成した和のトーン
- 青海波のパターン、うなぎのエンブレム、浜名湖のイメージマップ、夕景のイラストはすべて SVG で描画
- 写真素材は使用せず、外部依存は Google Fonts のみ
- 明朝体（Shippori Mincho）を軸に、Cormorant Garamond を欧文アクセントとして使用
- スクロールリビール、ヘッダーの状態変化、モバイルメニュー、FAQ アコーディオンなどの軽量なインタラクション

## ローカルで見る

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` を開いてください。

## アクセシビリティ

- スキップリンク、キーボード操作に対応したモバイルメニュー
- メニュー展開時は本文とフッターを `inert` にし、背景の操作を防止
- `prefers-reduced-motion` でアニメーションを抑制
- 装飾 SVG には `aria-hidden`、地図には代替テキストを設定
- JavaScript が読み込まれない場合でも、3秒後に全コンテンツを表示するフォールバックを実装
